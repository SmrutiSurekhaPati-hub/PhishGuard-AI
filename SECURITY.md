# Security Policy

## Overview

PhishGuard AI is a hackathon prototype designed to help users identify potentially suspicious phishing messages and URLs.

## Reporting a Security Issue

If you discover a security issue in this project, please report it privately to the project owner through GitHub rather than publicly exposing sensitive information.

When reporting an issue, please include:

- A clear description of the issue
- Steps to reproduce it
- Any relevant screenshots or error messages
- The potential impact of the issue

## Responsible Use

PhishGuard AI is intended for educational, awareness, and defensive cybersecurity purposes.

Users should:

- Avoid entering passwords, OTPs, API keys, financial information, or other sensitive personal information.
- Treat detection results as security warnings rather than absolute guarantees.
- Verify suspicious messages and URLs through trusted official channels.

## Data Handling

The prototype is designed to analyze user-provided message text and URLs for phishing-related indicators. Users should not submit confidential or sensitive information while using the application.

## Disclaimer

PhishGuard AI is a hackathon prototype and may produce incorrect classifications or risk assessments. It should not be considered a replacement for professional cybersecurity tools or security teams.
